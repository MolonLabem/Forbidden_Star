# Рабочий глоссарий TDL

Новые собственные имена — редакторский черновик. Устойчивые игровые термины следуют текущим картам и FAQ; аналогичные эффекты перечислены в `review.md`.

| Оригинал / маркер | Русское обозначение |
|---|---|
| `[D]` / die | 1 обычный куб; не особый тип куба |
| `[B]` / Bolter die | куб болтера (атака) |
| `[S]` / Shield die | куб щита (защита) |
| `[M]` / Aquila die | куб морали |
| `(B)` / Bolter token | жетон атаки |
| `(S)` / Shield token | жетон защиты |
| convert | перевернуть куб на указанную грань |
| reroll | перебросить куб |
| rout / routed / unrouted | деморализовать / деморализованный / недеморализованный |
| rally | восстановить отряд |
| retreat | отступить |
| execution round / game round | раунд битвы / раунд игры |
| assess damage step | шаг нанесения повреждений |
| reinforcement step | шаг подкрепления |
| command / combat / health / morale value | командный уровень / боевой показатель / показатель здоровья / показатель морали |
| assets / materiel | ресурсы / материалы |
| friendly / hostile / uncontrolled / contested | дружественный / враждебный / неконтролируемый / оспариваемый |
| world / area / system / void | мир / область / система / пустота |
| Advance / Strategize / Dominate / Deploy Order | приказ Продвижения / Стратегии / Доминирования / Развертывания |
| Planning / Operations Phase | Фаза Планирования / Фаза Действий |
| resolution phase | фаза разрешения — нестандартный термин оригинала, требуется подтверждение |
| Scheme / Tactic | План / Тактика |
| forge / reinforcement / cache token | жетон кузницы / подкрепления / запасов; слова хранятся в JSON, значки только в представлении |
