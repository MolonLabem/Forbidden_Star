## Данные и FAQ

Названия и термины FAQ согласуются с `page/factions/*/*/text.json`, а для карт с текстом на изображениях — с `page/data/cardnames.json`. Уточнения правил также основаны на поле **Note** [публичной библиотеки FS League](https://fixed-crane-287.notion.site/387346118c5d80caa6c1d8d50a60bc74?v=388346118c5d80308e06000cf1c80ca0). Каждая использованная запись имеет ссылку `Source` в `page/data/FAQ.json`. Правила сообщества, например запрет отступления через «Орчью Булыгу», обозначены отдельно; они не объявляются официальными правилами. Информация о RNB не включается.

Для показа фракции требуется успешная загрузка её `text.json`: часть изображений содержит только шаблон. При ошибке загрузки карточек или FAQ интерфейс предлагает повторить запрос без перезагрузки страницы. Список `filenames`, если задан, должен соответствовать именам файлов на диске.

Проверки данных без установки зависимостей: `node --test tests/data.test.cjs`.
